Luồng dùng nhanh

  1. Cập nhật Danh sách khoa khi nhân sự thay đổi.
  2. Cập nhật Danh mục số người thủ thuật khi quy định số người/thời gian thay đổi.
  3. Chọn file Excel làm việc và bấm Kiểm tra.
  4. Kết quả có bộ lọc, in A4 ngang và nút tải báo cáo Excel.
  5. Danh sách và danh mục được commit vào GitHub để các điện thoại/máy tính dùng chung một bộ dữ liệu.

Hướng dẫn GitHub Pages

  1. Tạo repository GitHub và tải toàn bộ nội dung thư mục này lên nhánh main.
  2. Vào Settings → Pages, phần Build and deployment chọn Deploy from a branch.
  3. Chọn nhánh main, thư mục /(root), rồi lưu.
  4. Mở đường link GitHub Pages mà GitHub cung cấp. Không cần Python, Flask hay máy chủ riêng.
Lưu dữ liệu: danh sách nhân viên được lưu tại data/staff.json và danh mục thủ thuật tại data/rules.json trong repository GitHub. localStorage chỉ là bộ nhớ đệm dự phòng.
Quyền riêng tư: file Excel bệnh nhân vẫn chỉ được xử lý trên thiết bị. Chỉ danh sách nhân viên/danh mục thủ thuật được đưa lên GitHub. Nếu repository là Public thì các file JSON này cũng là dữ liệu công khai.
Quyền cập nhật GitHub: lần đầu bấm Cập nhật, ứng dụng sẽ yêu cầu Fine-grained Personal Access Token có quyền Contents: Read and write cho đúng repository. Token chỉ giữ trong phiên trình duyệt, không được ghi vào mã nguồn.
