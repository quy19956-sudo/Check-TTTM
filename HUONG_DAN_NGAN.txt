BẢN GITHUB PAGES - ĐỒNG BỘ DANH SÁCH/DANH MỤC TRỰC TIẾP VỚI GITHUB

1. Upload toàn bộ nội dung gói này lên repo quy19956-sudo/Check-TTTM, branch main.
2. GitHub Pages: Settings -> Pages -> Deploy from a branch -> main -> /(root).
3. Tạo Fine-grained Personal Access Token chỉ cho repo Check-TTTM, quyền Contents: Read and write.
4. Khi bấm Cập nhật danh sách / Cập nhật danh mục, dán token khi ứng dụng hỏi.
5. Dữ liệu sẽ được commit vào:
   - data/staff.json
   - data/rules.json
6. Máy khác mở cùng trang và tải lại sẽ dùng dữ liệu mới.

Token KHÔNG được ghi vào repository.
File Excel bệnh nhân vẫn chỉ xử lý trên thiết bị và không upload lên GitHub.
Nếu repo Public, staff.json/rules.json cũng có thể được xem công khai.
